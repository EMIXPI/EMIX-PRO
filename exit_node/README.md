# EMIX Exit Node — سرور خروج رایگان برای چندلوکیشن شدن EMIX PRO

یک سرور VLESS-over-WebSocket مینیمال (فقط ۱ فایل) که روی هر پلتفرم رایگان deploy می‌شود
و دامنه‌اش را در پنل EMIX به‌عنوان **لوکیشن خروج** ثبت می‌کنید — خروجی ترافیک شما
به همان کشوری می‌رود که سرور deploy شده است.

```
کاربر ──► بهترین IP کلادفلر ──► Worker گیت‌وی ──► این سرور ──► اینترنت
                                    (/loc/eu/...)     رژیون دلخواه
```

## استقرار روی Railway (سریع‌ترین راه — ۲ دقیقه)

1. این ریپو (EMIX-PRO) را در Railway به‌عنوان **سرویس جدید** deploy کن:
   - پروژه‌ی Railway خودت → **+ New Service** → **GitHub Repo** → `EMIXPI/EMIX-PRO`
   - **Root Directory:** `exit_node`
   - **Region:** `Frankfurt (eu-central1)` برای اروپا — یا هر رژیون دیگر
2. بعد از ساخت سرویس: **Settings → Variables** اضافه کن:
   - `UUID` = UUID یکی از کانفیگ‌های پنل EMIX (از صفحه‌ی کانفیگ‌ها کپی کن)
3. بعد از deploy، دامنه‌ی `xxx.up.railway.app` سرویس را بردار
4. در پنل EMIX → تب گیمینگ → لوکیشن‌های خروج:
   - کد: `eu` · نام: `اروپا — فرانکفورت` · پرچم: `🇩🇪` · دامنه: `xxx.up.railway.app` → افزودن
5. تمام! در ساخت کانفیگ گیمینگ، لوکیشن `eu` را انتخاب کن

> می‌توانی چند سرویس با رژیون‌های مختلف بسازی (مثلاً یکی Frankfurt و یکی Singapore)
> و هرکدام را با کد جدا ثبت کنی — هر کدام یک خروج مستقل است.

## Koyeb (بدون کارت اعتباری)

- koyeb.com → Create Service → GitHub → همین ریپو → **Dockerfile** → Region: Frankfurt
- متغیر `UUID` را ست کن، دامنه‌ی koyeb.app را در پنل ثبت کن

## Render (۷۵۰ ساعت/ماه — بعد از ۱۵ دقیقه بی‌کاری می‌خوابد)

- render.com → New → Web Service → همین ریپو → Region: Frankfurt → متغیر `UUID`

## نکته‌ها

- سرور **TCP-only** است — دقیقاً مثل بک‌اند اصلی EMIX؛ بازی‌ها و مرور کامل کار می‌کنند
- TLS را خود پلتفرم terminate می‌کند — هیچ گواهی و پورتی لازم نیست باز شود
- احراز هویت با همان UUID کانفیگ پنل انجام می‌شود — UUID غلط فوراً قطع می‌شود
- برای چند کانفیگ: چند سرویس بساز یا فقط UUID کانفیگ اصلی را ست کن
- مانیتورینگ: `/health` و `/api/ping` و `/` همگی JSON وضعیت می‌دهند
- مصرف منابع: ~۳۰MB RAM و CPU نزدیک صفر — روی پلن ری‌یلوی فعلی عملاً رایگان
